# yoo-be-screenshot

Chrome / Edge（Manifest V3）浏览器截图扩展：可视区域、整页滚动拼接、框选区域；可选在图片底部附加当前页面 URL。

## 安装（开发者模式）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本仓库目录

## 使用

1. 点击工具栏图标打开弹窗
2. 选择截图方式，按需勾选「添加当前 URL」（默认开启）
3. 点击「开始截图」  
   - 框选 / 整页模式会自动关闭弹窗，在页面上完成操作

## 开发

本项目为纯静态扩展，无需构建步骤。
