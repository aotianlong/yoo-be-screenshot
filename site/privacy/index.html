Yoo Screenshot 隐私政策

最后更新：2026-11-11

Yoo Screenshot（「Yoo 截图」）是一款浏览器截图扩展。使用本扩展即表示你理解并同意本政策。

我们收集哪些数据

本扩展不运营开发者自有后端服务器，不将截图上传至开发者服务器，不使用第三方分析或广告 SDK。

在设备上可能处理或保存的数据包括：

  • 截图图像 — 仅在你主动截图、编辑或下载时存在于浏览器内存或会话存储中；关闭浏览器后，编辑会话数据会被清除。
  • 页面 URL 与标题 — 用于生成默认文件名；若你开启「添加当前 URL」，URL 会绘制在图片底部并随下载保存在本地，不会发送给我们。
  • 默认设置 — 截图方式、图片格式等偏好，通过浏览器存储 API 保存；若启用 Chrome 同步，可能经你的 Google 账号在其他设备间同步（由 Google 按其隐私政策处理）。

我们如何使用数据

上述数据仅用于截图、编辑、下载与保存你的偏好设置。

数据分享

我们不会出售、出租或与第三方分享你的截图或浏览内容。

权限

扩展所请求的权限仅在用户主动操作时使用，用于完成截图与保存文件，详见 Chrome 网上应用店说明。

数据删除

  • 卸载扩展可清除本地扩展数据。
  • 编辑中的截图保存在浏览器会话中，关闭浏览器后会失效。
  • Chrome 同步的设置可在 Chrome 同步设置中管理。

儿童

本扩展不面向 13 岁以下儿童，也不会故意收集儿童信息。

政策变更

如有重要变更，我们会更新本页面顶部的日期。
