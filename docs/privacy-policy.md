# Yoo Screenshot 隐私政策

**最后更新：2026-11-11**

Yoo Screenshot（「Yoo 截图」）由扩展作者提供。使用本扩展即表示你理解并同意本政策。

## 我们收集哪些数据

本扩展**不**运营后端服务器，**不**将截图上传至开发者服务器，**不**使用第三方分析或广告 SDK。

在设备上可能处理或保存的数据包括：

1. **截图图像** — 仅在你主动截图、编辑或下载时存在于浏览器内存或会话存储中；关闭浏览器后，编辑会话数据会被清除。
2. **页面 URL 与标题** — 用于生成默认文件名；若你开启「添加当前 URL」，URL 会绘制在图片底部并随下载保存在本地，不会发送给我们。
3. **默认设置** — 截图方式、图片格式、是否附加 URL 等偏好，通过 Chrome 的 `storage` API 保存；若浏览器启用同步，这些设置可能通过你的 Google 账号在其他设备间同步（由 Google 处理，见其隐私政策）。

## 我们如何使用数据

上述数据仅用于本扩展的核心功能：截图、编辑、下载与保存你的偏好。

## 数据分享

我们不会出售、出租或与第三方分享你的截图或浏览内容。

## 权限

扩展请求的权限仅用于在用户操作时完成截图与保存文件，详见商店说明。

## 数据删除

- 卸载扩展可清除本地扩展数据。
- 编辑中的截图保存在浏览器会话中，关闭浏览器后会失效。
- Chrome 同步的设置可在 Chrome 同步设置中管理。

## 儿童

本扩展不面向 13 岁以下儿童，也不会故意收集儿童信息。

## 政策变更

如有重要变更，我们会更新本页面日期。商店版本更新时可能同步修订说明。
